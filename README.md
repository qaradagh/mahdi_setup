# mahdi_setup

## اندیکاتور «سویینگ سه‌کندلی — نقدینگی سویینگ وسط»

فایل: [`indicators/three_candle_swings.pine`](indicators/three_candle_swings.pine)
پلتفرم: TradingView (Pine Script v6) — طراحی‌شده برای **داوجونز (US30 / YM / DJI) تایم‌فریم ۵ دقیقه**

### منطق کار

**سطح ۱ — سویینگ سه‌کندلی (با پشتیبانی از های/لوی برابر):**

کندل‌های کنارِ هم که **های برابر** (یا **لوی برابر**) دارند، یک «فلات» و در حکم **یک کندل** حساب می‌شوند.
یک فلات وقتی سویینگ سقف است که کندل قبل و کندل بعدش های **پایین‌تر** داشته باشند؛ و وقتی سویینگ کف است که کندل قبل و بعدش لوی **بالاتر** داشته باشند.

| حالت | نتیجه |
|---|---|
| یک های بالا + دو های پایین‌تر (کلاسیک) | سویینگ سقف ✔ |
| دو کندل با های برابر + کندل پایین‌تر دو طرف | سویینگ سقف ✔ |
| سه کندل با های برابر + کندل پایین‌تر دو طرف | سویینگ سقف ✔ |
| فلات وسط یک روند نزولی (کندل چپش بالاتر) | سویینگ نیست ✘ |

هر فلات **دقیقاً یک** سویینگ می‌سازد (نه یکی به‌ازای هر کندل) و به **اولین کندل فلات** لنگر می‌خورد.
مبنای برابری: اختلاف کمتر از نصف یک تیک (`syminfo.mintick`).

**سطح ۲ — سویینگ مدنظر ما (همون که مهمه):**

یک سویینگ سه‌کندلیِ سطح‌۱ که:

1. در **چپ** آن یک سویینگ سه‌کندلی هم‌نوع وجود داشته باشد،
2. در **راست** آن یک سویینگ سه‌کندلی هم‌نوع وجود داشته باشد،
3. و سویینگ وسط از هر دو همسایه **بالاتر** (برای سقف) یا **پایین‌تر** (برای کف) باشد.

سویینگ وسط = سقف / کف / نقدینگی. روی چارت با برچسب `H` یا `L` و یک خط افقی نمایش داده می‌شود.

> چرا همسایه‌ها هم‌نوع‌اند؟ چون هر سقفی طبیعتاً در چپ و راستش کف دارد؛ اگر همسایه را کف بگیریم شرط همیشه برقرار است و بی‌معنی می‌شود.

اینجا هم برابری پذیرفته می‌شود: اگر سویینگ وسط با سویینگ سمت راستش **دقیقاً هم‌قیمت** باشد (دابل‌تاپ / دابل‌باتم)، باز هم سطح ساخته می‌شود و روی **اولی** قرار می‌گیرد تا یک خط هر دو تاچ را پوشش دهد.

### فیلتر تأیید (کدام سویینگ‌ها باقی می‌مانند)

از بین سویینگ‌های وسط، فقط آن‌هایی روی چارت می‌آیند که قیمت آن‌سوی **کندلِ سویینگ سمت راست** کلوز کرده باشد:

- سویینگ **سقف** → یک کلوز **زیر لوی** آن کندل
- سویینگ **کف** → یک کلوز **بالای های** آن کندل

نکته‌ها:

- ملاک فقط **کلوز** است؛ شادوزدن یا تاچ‌کردن کافی نیست.
- اگر سویینگ سمت راست یک **فلات** باشد، کندل مرجع **راست‌ترین کندل فلات** است.
- جست‌وجو فقط از **کندل بعدِ کندل مرجع** شروع می‌شود؛ کلوزهای قبل از تشکیل سویینگ راست شمرده نمی‌شوند.
- مرجع همیشه **اولین و نزدیک‌ترین** سویینگ سمت راستِ همان سویینگ وسط است و **عوض نمی‌شود**؛ سویینگ‌هایی که بعداً ساخته می‌شوند مرجع را جابه‌جا نمی‌کنند (با `Neighbour swings` بزرگ‌تر از ۱ هم همین‌طور).
- ساخته‌شدن یک سویینگ های جدید **پایین‌تر** از سطح، سطح را کنسل نمی‌کند؛ سطح همچنان منتظر کلوز زیر مرجع خودش می‌ماند. کنسل فقط وقتی است که خودِ سطح زده شود.
- تا آمدن آن کلوز، سطح **در انتظار** است و رسم نمی‌شود. اگر قیمت قبل از آن خودِ سطح را بردارد، سطح برای همیشه حذف می‌شود.
- `Show swings still waiting` سطح‌های در انتظار و خط مرجعشان را خط‌چین نشان می‌دهد — برای بررسی قانون مفید است.
- `Keep only swings confirmed...` را خاموش کنی، رفتار قبلی برمی‌گردد (همهٔ سویینگ‌های وسط رسم می‌شوند).

### زمان تأیید (مهم)

سویینگ سطح‌۲ فقط وقتی قابل تشخیص است که سویینگ سه‌کندلیِ سمت **راست** ساخته شده باشد.
پس سطح چند کندل بعد از کندل واقعی سویینگ چاپ می‌شود، ولی خط و برچسب به **کندل واقعی سویینگ** لنگر می‌خورند و بعد از تأیید دیگر جابه‌جا نمی‌شوند (ری‌پینت ندارد).

اگر قیمت **قبل از تأیید** آن سطح را برداشته باشد، اندیکاتور آن را از همان ابتدا «swept» علامت می‌زند و خطش را همان‌جا می‌بندد (خط زنده و گمراه‌کننده رسم نمی‌کند).

### تنظیمات

| تنظیم | کار |
|---|---|
| Neighbour swings on each side | تعداد سویینگ همسایه در هر طرف (پیش‌فرض ۱ = یکی چپ، یکی راست). ۲ یا ۳ = سویینگ با درجه بالاتر |
| Keep only swings confirmed by a close past the right swing | روشن/خاموش‌کردن فیلتر تأیید |
| Show swings still waiting | نمایش خط‌چینِ سطح‌های در انتظار به‌همراه خط مرجعشان |
| Merge levels sitting at the same price | جلوگیری از رسم دو خط روی هم وقتی دو سویینگ وسطِ جدا دقیقاً هم‌قیمت‌اند |
| Detect swings on closed bars only | جلوگیری از ظاهر/محو شدن سویینگ در کندل باز |
| Show level-1 swings | نمایش سویینگ‌های سه‌کندلی ساده (مثلث‌های ریز) برای بررسی چشمی |
| Keep last N levels per side | تعداد سطح نگه‌داشته‌شده در هر سمت |
| Sweep confirmed by | برداشت نقدینگی با **Wick** یا **Close** |
| Keep swept levels | سطح‌های برداشته‌شده خط‌چین خاکستری بمانند |

### آلارم‌ها

- Middle swing HIGH / LOW confirmed — لحظهٔ **تأیید** سویینگ وسط (نه لحظهٔ تشکیل آن)
- Sell-side / Buy-side liquidity taken — برداشت نقدینگی سقف/کف
- هر چهار مورد هم به‌صورت `alertcondition` و هم `alert()` با قیمت در متن پیام

### نصب

TradingView → Pine Editor → محتوای فایل را paste کنید → **Add to chart**.
