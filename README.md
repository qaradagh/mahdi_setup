# mahdi_setup

## اندیکاتور «سویینگ سه‌کندلی — نقدینگی سویینگ وسط»

فایل: [`indicators/three_candle_swings.pine`](indicators/three_candle_swings.pine)
پلتفرم: TradingView (Pine Script v6) — طراحی‌شده برای **داوجونز (US30 / YM / DJI) تایم‌فریم ۵ دقیقه**

### منطق کار

**سطح ۱ — سویینگ سه‌کندلی (فرکتال):**

- سقف: `High[i] > High[i-1]` و `High[i] > High[i+1]`
- کف: `Low[i] < Low[i-1]` و `Low[i] < Low[i+1]`

**سطح ۲ — سویینگ مدنظر ما (همون که مهمه):**

یک سویینگ سه‌کندلیِ سطح‌۱ که:

1. در **چپ** آن یک سویینگ سه‌کندلی هم‌نوع وجود داشته باشد،
2. در **راست** آن یک سویینگ سه‌کندلی هم‌نوع وجود داشته باشد،
3. و سویینگ وسط از هر دو همسایه **بالاتر** (برای سقف) یا **پایین‌تر** (برای کف) باشد.

سویینگ وسط = سقف / کف / نقدینگی. روی چارت با برچسب `H` یا `L` و یک خط افقی نمایش داده می‌شود.

> چرا همسایه‌ها هم‌نوع‌اند؟ چون هر سقفی طبیعتاً در چپ و راستش کف دارد؛ اگر همسایه را کف بگیریم شرط همیشه برقرار است و بی‌معنی می‌شود.

### زمان تأیید (مهم)

سویینگ سطح‌۲ فقط وقتی قابل تشخیص است که سویینگ سه‌کندلیِ سمت **راست** ساخته شده باشد.
پس سطح چند کندل بعد از کندل واقعی سویینگ چاپ می‌شود، ولی خط و برچسب به **کندل واقعی سویینگ** لنگر می‌خورند و بعد از تأیید دیگر جابه‌جا نمی‌شوند (ری‌پینت ندارد).

اگر قیمت **قبل از تأیید** آن سطح را برداشته باشد، اندیکاتور آن را از همان ابتدا «swept» علامت می‌زند و خطش را همان‌جا می‌بندد (خط زنده و گمراه‌کننده رسم نمی‌کند).

### تنظیمات

| تنظیم | کار |
|---|---|
| Neighbour swings on each side | تعداد سویینگ همسایه در هر طرف (پیش‌فرض ۱ = یکی چپ، یکی راست). ۲ یا ۳ = سویینگ با درجه بالاتر |
| Allow equal highs / lows | با `>=` در سمت چپ، اکوال‌های (Double Top/Bottom) هم شمرده می‌شوند |
| Detect swings on closed bars only | جلوگیری از ظاهر/محو شدن سویینگ در کندل باز |
| Show level-1 swings | نمایش سویینگ‌های سه‌کندلی ساده (مثلث‌های ریز) برای بررسی چشمی |
| Keep last N levels per side | تعداد سطح نگه‌داشته‌شده در هر سمت |
| Sweep confirmed by | برداشت نقدینگی با **Wick** یا **Close** |
| Keep swept levels | سطح‌های برداشته‌شده خط‌چین خاکستری بمانند |

### آلارم‌ها

- Middle swing HIGH / LOW formed — تشکیل سویینگ وسط
- Sell-side / Buy-side liquidity taken — برداشت نقدینگی سقف/کف
- هر چهار مورد هم به‌صورت `alertcondition` و هم `alert()` با قیمت در متن پیام

### نصب

TradingView → Pine Editor → محتوای فایل را paste کنید → **Add to chart**.
